# 여정 악화 알림 정책 (#428) — 경로당 1번·조용한 갱신·할 일 담기

## 뭘 하나
악화 알림이 **경로 버전마다 한 번만 울리게** 한다. 그 뒤에 더 나빠지거나 다른 환승이 나빠지면 새로 울리지 않고 **이미 떠 있는 알림을 조용히 고쳐 쓴다.** 문구는 상태가 아니라 **할 일**을 말한다.

비유: 처음 한 번만 어깨를 두드리고, 그 뒤 바뀐 내용은 메모지를 바꿔 끼워 두는 비서.

## 왜
- 지금은 환승마다·단계(빠듯/놓침)마다 따로 울려 한 여정에서 여러 번 진동할 수 있다
- 문구가 "환승 시간이 빠듯해요 / 앱에서 새 안내를 확인하세요" — 할 일이 없다
- 배포 전이라 전환율은 못 잰다 → 원칙을 세우고 테스트로 보장하는 것이 결과물

## 핵심 결정
1. **울림 = 경로 버전당 1번** (위험·재탐색 합쳐서). 접근 알림("갈아탈 차 곧 도착")은 제외
2. **"울릴 권리"를 여정 행에 한 번만 따낸다** — 알림 행 개수를 세지 않는다. 위험 알림(평가기)·재탐색 알림·보드 push 가 서로 다른 트랜잭션·인스턴스에서 동시에 돌아, 세는 방식은 둘 다 "0건 → 울림"을 낸다(Opus 검토). 여정 행 UPDATE 한 번으로 따내면 DB 가 하나만 이기게 해 준다
3. **물려받기**: 아직 안 나간 울림 알림을 더 나쁜 알림이 대체하면(빠듯→놓침, 위험→재탐색 합침) 대체한 쪽이 울린다 — 안 그러면 울림이 0번
4. **돌려받기**: 울림 알림이 만료·실패로 실제로 안 나가면 권리를 돌려놓는다 — 다음 악화가 울린다
5. **조용한 갱신**: 같은 경로 버전 알림은 갱신 열쇠 하나로 덮고, iOS 는 `passive`(소리·진동 없음). Android 는 조용한 채널이 있는 앱에만 보내고, **없는 앱(구버전)에는 아예 안 보낸다**(존재하지 않는 채널은 소리 나는 기본 채널로 떨어짐)
6. 조용한 위험 알림은 더 쓸모 있는 알림을 덮지 않는다: 접근 알림을 취소하지 않고, 이미 울린 게 재탐색 제안이면 조용한 위험 알림은 보내지 않음
7. **문구 = 할 일 + 보낸 순간의 숫자**(만료로 낡은 숫자 방지). 빠듯: "2호선이 3분 뒤 와요 — 서두르면 탈 수 있어요" / 놓침+대안: "환승을 놓쳤어요 · ○○에서 7호선 타면 4분 빨라요" / 놓침+대안 없음: "다음 2호선은 14:32"
8. **합치기 창**: 첫 울림은 다음 수집 결과를 받아 본 뒤 보낸다 — 빠듯·놓침(대안 없음) 수집 1번, 놓침(대안 계산 중) 수집 2번(최대 30초). 그 사이 더 나쁜 소식·대안이 오면 대체해 한 번에. 다음 차가 더 빨리 오면 즉시
9. 플래그 기본 꺼짐, 끄면 지금 메시지와 바이트까지 같음

## 사람이 볼 곳 (경계 리뷰)
- **상태 전이**: 울릴 권리 = 없음 → 따냄(경로 버전 기록) → [물려받기: 대체 알림으로 이동] → [돌려받기: 만료·실패 시 비움]. 재탐색 수락으로 경로 버전이 바뀌면 자연히 새 권리
- **실패 경로**: 권리를 딴 알림이 만료·발송 실패 → 권리 반납 → 다음 악화가 울림. 반납 안 하면 사용자는 한 번도 못 받음
- **플래그·기본값**: `fatigue.enabled=false`, Android 조용한 갱신은 토큰이 `quietChannel` 능력을 알린 경우만
- **계약**: 마이그레이션 2개(여정 행 울림 권리 칼럼, push 토큰 능력 칼럼), FCM data 에 `delivery`(ALERTING/QUIET), 앱 인계(Android 채널 + 토큰 등록 시 능력 전송, 포그라운드에서 QUIET 배너 숨김 — 필수)

- **PR-1b 판정**: 울릴 권리 칼럼(마이그레이션)·물려받기·돌려받기, 세 쓰기 경로 같은 잠금 순서

## 리스크
- 앱 업데이트 전 Android 사용자는 조용한 갱신을 못 받는다(울림 1번만 받고 이후 변화는 앱 화면에서) — 의도된 안전 쪽
- 기존 함정: 회복 뒤 같은 상태로 다시 악화되면 중복 키로 알림 행이 안 생긴다 → 계약 테스트로 현재 동작을 고정하고 노트에 기록

## 검증법
계약 테스트 — 빠듯→놓침(보드 20초 지연 중 포함) = 울림 1 / 환승 2개 동시 악화 = 울림 1 / 보드가 위험 대체 = 울림 1 / **평가기와 보드 push 동시 실행 = 울림 1**(두 스레드 시험) / 울림 알림 만료 → 다음 악화 울림 / 경로 버전 +1 → 다시 울림 1 / 채널 2개여도 판정 1번 / Android 능력 없음 = 조용한 갱신 미발송 / 플래그 끔 바이트 동일. 이후 #427 부하에서 "경로 버전당 울림 2번 이상 = 0" 감사 쿼리.
