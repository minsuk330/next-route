# 모바일 인계 — 지도 정류장 전국 타일 (#326)

## 요약
지도 정류장을 **서울 1.3만 개 → 전국 20.6만 개**로 바꾼다. 한 번에 받지 않는다.
- 0.1°(약 11km) 타일로 나눴다. **화면에 보이는 타일만** 받고, **바뀐 타일만** 다시 받는다.
- 마커 키는 **gtfsStopId** 다. 근처 목록·노선 조회·추적과 같은 id 다.
- 기존 v1 `/api/map/bus-stops/snapshot`(서울 9자리)은 그대로 있다. 새 앱으로 다 넘어가면 지운다.

## 1. 목록(manifest) — 앱 시작 시 1회
```
GET /api/map/bus-stops/v2/tiles
If-None-Match: "<저장해 둔 version>"
```
```json
{"version":"0123456789ab","tileSize":0.1,"count":205947,
 "tiles":{"374_1270":"abcdef123456","375_1269":"…"}}
```
- 304 → 로컬 목록을 그대로 쓴다.
- 200 → 새 목록을 저장한다. **로컬 타일 중 tileVersion 이 달라진 것만** 낡은 것으로 표시한다.
- 503(`Retry-After: 30`) → 서버가 부팅 직후 아직 만드는 중이다. 로컬 데이터로 그리고, 30초 뒤 다시 시도한다.
- `Cache-Control: no-cache` 다. HTTP 캐시를 쓰더라도 매번 재검증한다.

## 2. 타일 — 화면에 필요할 때
```
GET /api/map/bus-stops/v2/tiles/{key}?v={목록의 tileVersion}
```
```json
{"key":"374_1270","version":"abcdef123456",
 "columns":["gtfsStopId","name","lat","lng","arsId"],
 "stops":[["1:BS_TAGO_SEB121000009","신분당선강남역",37.4958,127.029,"22010"]]}
```
- **key 계산(계약):** `floor(lat * 10) + "_" + floor(lng * 10)`.
  - 반드시 `* 10` 후 floor 한다. **`/ 0.1` 을 쓰면 안 된다.** 부동소수 오차 때문에 경계 칸 300여 곳이 틀린다.
  - 음수는 없다(한국).
- 화면 bbox + 패딩(1.5배)이 걸치는 key 를 모두 구한다. 그중 **목록에 있는 key 만** 요청한다. 바다·빈 칸은 404 다.
- `?v=` 를 목록의 버전과 같게 주면 `Cache-Control: immutable, 1년` 이 붙는다. 그 URL 은 영원히 같은 본문이다.
- `columns` 로 열 순서를 한 번 검증한다. 열이 늘면 뒤에 붙는다.
- `arsId` 는 서울 정류장만 있고, 나머지는 **null** 이다(빈 문자열 아님).
- 타일 크기는 gzip 중간값 1.5kB, 최대 31kB 다. 서울 화면 하나는 100kB 이하다.
- 로컬 저장은 타일별로 한다(key → version + 본문). 상한을 두고 LRU 로 지우는 것을 권장한다. 전국 전부 받아도 2.8MB 다.

## 3. 마커를 눌렀을 때
- 노선: `GET /api/journeys/track/stops/{gtfsStopId}/patterns`.
  - 같은 정류장의 서울·경기·인천 노선이 전부 온다(#327).
  - 노선 행의 도착 조회는 `Direction.arrivalStopId` 를 쓴다(#327 HANDOFF).
  - ⚠ 이 경로는 현재 로그인이 필요하다(서버에서 로그인 제거 작업이 진행 중).
- 같은 정류장은 타일에 **한 점**만 있다. 대표는 서울 → 경기 → 인천 순이고, 근처 목록의 id 와 같다.

## 4. 그리기 (#160 HANDOFF 4항목 그대로)
1. 마커 upsert. clear-and-redraw 를 하지 않는다. 키는 gtfsStopId 다.
2. 셀 인덱스. 타일 key 를 그대로 셀로 써도 된다.
3. 줌 게이팅·클러스터. 전국이라 더 중요하다.
4. 파싱과 인덱스 구축은 메인 스레드 밖에서 한다.

## ETag·압축
- 응답 ETag 는 **약한 형식** `W/"<버전>"` 이다. `If-None-Match` 에는 받은 값을 그대로 돌려보내면 된다. 따옴표만 있는 형식도 받는다.
- `Accept-Encoding: gzip` 을 꼭 보낸다. 서울 타일 하나가 raw 58kB 에서 gzip 수 kB 로 준다.

## 갱신 주기
서버는 하루 1회 다시 만든다. 내용이 같으면 버전도 같다. 앱은 시작할 때 목록을 1회 재검증하면 충분하다.
