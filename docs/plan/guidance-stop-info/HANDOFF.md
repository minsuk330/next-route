# 안내 스냅샷 지점 줄 값 — 앱 인계 (#266)

여정 스냅샷 `legs[]`(JourneyLegView)에 **추가만** 된다. 전부 nullable — **없으면 그 줄을 숨긴다.** 값은 여정을 만들 때 정해지고 진행 중에 바뀌지 않는다(재탐색 수락 시 새 하차점이면 하차 쪽만 바뀐다). 내리는 문 방향은 #335(데이터 대기).

| 필드 | 단계 | 뜻 | 예시 줄 |
|---|---|---|---|
| `startStopNo` | WAIT_BUS·RIDE_BUS | 승차 정류장 번호(표지판 번호). 대기 단계는 `endStopNo` 도 같은 값 | `건국대학교(후문.시내방향) 승차` 아래 `05229` |
| `endStopNo` | RIDE_BUS | 하차 정류장 번호 | |
| `directionName` | WAIT_SUBWAY·RIDE_SUBWAY | 승차역 **다음 역 이름** — 앱이 "{이름} 방면"으로 붙인다 | `충무로 방면` |
| `startExitNo` | WAIT_SUBWAY·RIDE_SUBWAY | 승차역에 **들어가는** 출구(앞 도보 줄: "OO역 N번 출구로") | `3` |
| `endExitNo` | RIDE_SUBWAY | 하차역에서 **나가는** 출구(다음 도보 줄: "OO역 N번 출구에서 도보") | `1` |
| `fastAlight` | RIDE_SUBWAY | 빠른 하차 칸·문 목록 `[{carDoor:"2-3", facility:"STAIRS"}]` — PR-4 | `빠른 하차: 2-3` |

- 지오메트리 `legs[].stops[].stopNo`: 버스 정류장 목록 펼치기용. 서울 노선표 경로만 채운다.
- 정류장 번호 범위: 서울(99%), 경기 GBIS(약 92%), 지방 TAGO(표본 22/25 도시). 군 단위 일부 7자리 값은 표지판 번호가 아닐 수 있다.
- 방면: 1정거장 구간이거나 정차 목록을 모르면 null.
- 출구: 지하철↔지하철 환승(걷기 없이 바로 대기, 또는 걷기 뒤 지하철 대기)에는 없다. 역 반경 350m 안 출입구 중 다음(앞) 도보 목적지(출발지)에 가장 가까운 것 — 실제 길안내와 다를 수 있다. 출입구 데이터가 없는 역(연천·광명·도농·인천공항2터미널 등)은 null.
- **출구 데이터 출처 표기 필요**: OpenStreetMap(ODbL). 앱 정보 화면에 "© OpenStreetMap contributors" 문구를 넣어 달라.
