# 1~9호선 밖 도시철도 요일별 시간표 (L, slug `otp-day-types-other-lines`, 이슈 #557 후속)

## 결론
서울 1~9호선 밖 도시철도도 평일·토요일·휴일 운행을 나눈다. 출처는 철도데이터포털(KRIC) 파일 하나(열차 단위, 열차번호, 요일 구분).
노선을 KTDB 평일이 지금도 맞는지로 나눠 세 단계로 한다.
- **PR-A (평일 유지)**: KTDB 평일이 KRIC 평일과 관문(≥95%)을 넘는 노선은 평일을 그대로 두고 토·휴 운행만 더한다. otp-day-types PR-1 과 같은 방식,
  2h(apply_day_types.py)는 그대로 쓰고 데이터 파일만 늘어난다. **노선 분류는 계획에 고정하지 않고 도구 리포트(관문)로 정한다.**
  리뷰 실측(60초 창): 신림 1.00, 신분당 0.98~0.99, 대전 0.94, 수인분당 0.943(경계), 부산4 0.69(제외)
- **PR-B (평일 교체)**: 관문을 못 넘는 노선(KTDB 평일이 2025-03 뒤 개정으로 낡음)은 평일 운행까지 KRIC 로 바꾼다. 평일 경로가 바뀌므로 별도 PR, 별도 검증.
  후보: 경의중앙, 경춘, 경강, 서해, 동해, 공항, 의정부, 김포, 부산4 등(리포트로 확정). 인천1 은 검단 연장 3역이 KTDB 에 없어 평일 255/312편을 못 대응 → 제외
- **PR-C (TAGO)**: KRIC 에 시각이 없는 GTX-A, 대경선, 인천2, 에버라인. 역별 출발시각뿐이라 시발역 출발시각 + KTDB 역간 소요시간으로 운행을 잇는다

예: 수인분당선 정자역 하행. KRIC 평일 168편(상·하 336), 휴일 130편(260). 지금은 일요일에도 평일 168편으로 안내한다. PR-A 뒤에는 휴일 130편만 보인다.

## 사실 (조사 2026-11-09)
- KRIC 파일 "전체_도시철도운행정보_20260630.xlsx": `https://data.kric.go.kr/rips/dataset/download.file?type=filedata&id=900&operation=1`, 키 없음,
  17.9 MB, 223,425행, 포털 수정 2026-10-12. 열 `열차번호, 노선번호, 노선명, 운행구간기점명, 운행구간종점명, 운행유형, 요일구분, 운행구간정거장, 정거장도착시각,
  정가장출발시각(원문 오타), 운행속도, 운영기관전화번호, 데이터기준일자`(엑셀 일련번호: 46173 = 2026-05-31, 44804 = 2022-08-31)
- 형식 두 가지:
  - **row**(한 행 = 한 정거장, 시각 = 하루에 대한 소수): 코레일 노선(경강, 경부, 경의중앙, 경인, 경춘, 동해, 서해, 수인분당, 안산과천, 일산, 공항?), 광주
  - **multi**(한 행 = 한 열차, `001-역+002-역…` / `001-05:30+…`, 구분자 `+`·`,`·`/` 노선별, 첫·끝 역 `00:00` 자리표시): 대구, 대전, 부산, 김포(노선번호 L41G1~59 로 쪼개짐) 등
- 요일 구분 표기(노선별): `평일`/`휴일`(코레일·대전·인천·에버라인·서울9), `평일`/`토요일`/`휴일`(대구), `평일`/`토요일`/`공휴일`(부산1~3, 신분당), `평일`/`토요일`/`일요일`(부산4),
  `평일`/`토요일`/`휴일`/`명절`(광주), `토요일+일요일+공휴일`(김포), `토+공휴일`(의정부), `주말+공휴일`(신림), `토요일+휴일`(우이), `평일+토요일+공휴일`(부산김해, 매일 같음),
  서울 1~8호선 `토요일+공휴일`(otp-day-types 의 "토요일 = 휴일" 실측과 같다)
- **리뷰로 확인한 데이터 사실**(운영 zip 비서울 지하철 8,131 trip + KRIC):
  - 소수 시각 1.0 이상 0개. 자정 뒤는 0.00x(E 표기 `1.5625E-2`)로 되돌아감. 자리표시는 빈칸·`-:`·`:`·`  :  `이고 `00:00` 은 실제 시각일 수 있다(대전 1238 판암 00:00, 공항 A3293 00:00 출발)
  - 부산1~4·의정부: 종착역 시각이 아예 없다(도착 열 전부 빈칸, 출발 열 종착 `-:`)
  - 오타: 김포 평일 129/518편 중간 한 역(`05:32:39`), 인천1 1086 동춘, 신림 주말 31/312편 도착·출발 뒤집힘
  - 시발역 03:00 전 출발 열차가 있다(김포, 부산4, 신림, 신분당, 공항) → 24:xx 로
  - 광주 row 형식: 같은 열차번호가 한 요일에 여러 운행(왕복)으로 나온다. 대구3 역방향은 `운행구간정거장` 에 008~013 이 빠지고 시각에는 있다
  - 공항철도 `운행유형` `직통` 표마다 52편 — 직통은 그래프에서 빼기로 한 결정(subway-corrections `arex-direct-absent`)과 같이 거른다
  - 기준일자: 엑셀 일련번호와 ISO 문자열(신분당·의정부)이 섞임
  - 역 이름: 23개 노선 모두 한 route 안 같은 이름 역 0개. 별칭 약 50개 필요(코레일 약칭 신인천=인천, 신수원, 부교대, 디엠시…; 개명 동구청=큰고개, 서부정류장=성당못; 구두점 경성대.부경대, 4.19).
    광주는 기지사업소·옥동기지를 지나는 열차(평일 51/283) → 비영업 역 별칭 `null`(앞뒤 잘라냄)
  - transfers.txt 342행 전부 정류장 단위, frequencies.txt 없음
- 시각 없는 노선: 인천2, 에버라인은 행이 있지만 "운행시격 3~10분" 같은 문장뿐. GTX-A, 대경선은 행이 없음 → TAGO(`GetSubwaySttnAcctoSchdulList`, 열차번호 없음, 역별 dep/arr + `endSubwayStationId`)
- KTDB 평일 ↔ KRIC 평일 일치(60초, 역 이름 같은 역 합산, 조사 에이전트): 대구·부산·우이·광주·수인분당 ≥92%, 대전 93%, 신분당·신림 87~88%, 김포 83%, 서해 77%, 경강 74%,
  의정부 65%, 경춘 63%, 경의중앙 61%, 인천1 53%, 공항 49%, 동해 44%
- KRIC 기준일자가 오래된 노선: 부산1~4 2022-08, 우이 2022-05, 부산김해 2022-04, 의정부 2023-09. 관문(KTDB 2025-03 평일과 일치)이 실제로 바뀌었는지 보여준다
- 서버: GTFS service_id·지하철 trip_id 를 쓰는 곳 없음(otp-day-types 리뷰로 확인). 지하철 실시간 결속은 trainNo·lineId
- 2h `apply_day_types.py` 는 데이터 파일(routeId, trips[service M_SA/M_HO/M_SH, stops])만 보면 된다. 데이터 출처는 상관없다

## 설계

### 공통: `runner/kric_timetable_trips.py` (신규)
- `fetch --out DIR`: KRIC 파일을 받아 sha256 과 받은 날짜를 `source.json` 에 적는다. 원본은 커밋하지 않는다(17.9 MB, `data/gen/kric/`)
- 파싱: xlsx 는 zip + XML 이라 표준 라이브러리로 읽는다(`zipfile` + `xml.etree.iterparse`, sharedStrings). 새 라이브러리 없음
- 열차 단위로 모으기: row 형식은 (노선, 요일, 열차번호, 기점, 종점) 으로 파일 전체에서 모아 시각순 정렬하고, 같은 역이 다시 나오면 운행을 나눈다(왕복).
  multi 형식은 한 행을 정규식으로 쪼개고, 이름이 빠진 순번은 같은 노선 다른 열차의 순번→역 이름으로 채운다(역 수와 시각 수가 다르면 그 열차 실패)
- 시각 규칙: 자정 넘김은 앞 시각 ≥20:00 → 이번 시각 <04:00 일 때만 +24h. 시발역 출발 <03:00 → 전체 +24h. 그 밖의 역행 = 데이터 오류.
  중간 한 역만 튀면(앞뒤 역은 맞음) 그 역 시각을 비우고 틀 구간시간으로 채운다. 종착역 시각 없음(부산·의정부) → 직전역 출발 + 틀의 마지막 구간 소요시간.
  채운 시각은 운행에 `filled` 로 표시하고 `source.rule` 에 적는다. 그래도 안 되는 열차는 `badTimes` — 관문 분모에 넣는다
- 열차 번호가 한 요일에 겹치면(광주 왕복) 데이터 키 = `{열차번호}-{n}`. trip_id 가 겹치지 않게
- `운행유형` `직통`(공항) 은 거른다(그래프에서 직통을 뺀 결정과 같음)
- 요일 매핑 `config/otp-national/kric-day-types.json`(노선명 → 표기 → service):
  - `평일` → `M_WD` / `토요일` → `M_SA` / `휴일`·`공휴일`·`일요일` → `M_HO` / `토요일+…`·`주말+…`·`토+…` → `M_SH`
  - 토요일 표기가 없는 노선의 `휴일` → `M_SH`(토요일도 휴일 시각표, 코레일 광역전철 운영과 같음)
  - `명절`(광주) → 버림(공휴일 목록이 명절을 따로 갖지 않음, 리포트에 남김). 부산4 `일요일` → `M_HO`(평일 공휴일에도 일요일표를 쓰는 근사, 리포트)
  - `평일+토요일+공휴일`(부산김해) → 바꿀 것 없음(대상에서 뺀다)
- 역 이름 → GTFS stop_id: 노선의 KTDB route 정차역의 `stop_name` 과 KRIC 역 이름을 정규화(공백·괄호 노선 표기 제거)해 맞추고, 안 맞는 이름은
  `config/otp-national/kric-station-aliases.json`(노선명 → {KRIC 이름: GTFS stop_id 또는 null(비영업 역, 운행 앞뒤에서 잘라냄)}, 근거 한 줄)로.
  두 KRIC 이름이 같은 stop_id 로 가면 실패(일대일). 대응 못 한 이름이 있는 열차는 `unmapped` — 관문 분모에 넣는다
- route 배정, 관문, M_SH 판정은 `seoul_timetable_trips.py` 의 `assign_route`·`weekday_match`·`weekend_entries` 를 가져다 쓴다
  (`api_trains` 와 같은 모양 `{trainNo, origin, dest, express, stops: [(code, arr, dep)]}`). 방향은 열차 정차 순서로 정해지므로 INOUT 짝 추론은 필요 없다.
  `line_order`·`express_route_set` 은 부르지 않는다(경춘 GC, KJ-2 에서 branch 오류). `express_routes = set()`(실측 모호 배정 0)
- **정류장 코드 통일(리뷰 B1, 병합된 도구의 버그)**: 지금 `codes_of` 는 `RS_ACC1_S-1-` 접두가 있을 때만 떼고, `weekday_match` 의 `to_code` 는 무조건 12자를 자르고,
  출력은 `STOP_PREFIX + c` 다. 비서울 stop_id(S-2~S-5)에서 일치 0. → `stop_code(sid)` 하나로 패턴·열차·match 에 쓰고, 출력은 code → stop_id 역표로. 3·7·8·9호선 결과는 그대로여야 한다(시험)
- 관문: 창 60초(배차 3~5분 노선에서 300초는 관문이 안 됨) + 일치 쌍의 역별 시각 차 p90 ≤ 60초. unmapped·badTimes 열차는 분모에 넣는다
- 출력: PR-A = 기존 day-types 데이터 파일 형식 그대로(`config/otp-national/day-types/{routeId}.json`). `source` 에 KRIC URL, 파일 sha256, 기준일자, 노선명

### PR-A 평일 유지 노선
- 관문은 otp-day-types 와 같다(평일 일치 ≥95% 양쪽, 토·휴 unmatched ≤5%, 방향별). 통과한 route 만 데이터 파일
- 2h 변경 없음. 빌드는 `--day-types` 디렉터리에 파일이 늘어날 뿐
- 서로 다른 출처의 시각표가 한 그래프에 섞이는 건 이미 그렇다(서울 API 3·7·8·9호선)

### PR-B 평일 교체 노선
- 2h 변경 목록(리뷰 S6): `NEW_SERVICES` 에 교체용 `M_WD` 허용, `RUNS_ON` 에 평일 추가(새 M_WD 끼리 중복·추월), `Table` 에 원래 바이트를 유지하는 행 삭제,
  stop_times 를 줄 단위 + `trip_id_of`(0번 열 빠른 경로)로 걸러 복사
- 데이터 파일에 `"replaceWeekday": true` 와 `M_WD` 운행을 넣는다. 2h 가 그 route 의 KTDB 운행을 지우고(trips.txt 행 제거, stop_times.txt 는 스트리밍 복사하며 그 trip 행을 건너뜀)
  KRIC 평일 운행을 `M_WD` 로 붙인다. 틀은 지우기 전 KTDB 운행(같은 정차 목록, 아니면 연속 구간)에서 고른다 → shape·stop_sequence 유지
- 관문(교체용): KRIC 평일 열차 중 틀을 찾은 비율 ≥99%(평일 운행이 조용히 사라지면 안 됨). 빠지는 열차 목록을 리포트·PR 에 싣는다. 틀이 없는 패턴(KTDB 뒤 개통역, 새 급행 정차 패턴)은 리포트 → 그 노선은 실패하고 PR-B 에서 빠진다(신설역은 stops·shape 가 없어 이 방식으로 못 넣음, 범위 밖)
- 지우는 KTDB 운행 수와 넣는 KRIC 운행 수를 리포트. 시간대별 편수 비교표를 남긴다
- 2h 변경점: `replaceWeekday` 처리, stop_times 스트림 필터, 재적용 판정(교체된 route 는 원래 trip id 가 없다 → 데이터 trip 이 모두 있으면 alreadyApplied), 시험
- 평일 회귀 기준이 바뀐다: "옛 그래프와 같다" 대신 "교체 노선 평일 운행이 KRIC 와 같다 + 교체 안 한 노선은 옛 그래프와 같다"

### PR-C TAGO 노선 (GTX-A, 대경선, 인천2, 에버라인)
- TAGO 역별 시각(평일 01, 휴일 03; 토요일 02 는 대부분 0행 → 휴일을 `M_SH` 로)을 시발역 출발 + `endSubwayStationId` 로 열차 후보를 만들고,
  같은 (시발역, 종착역) KTDB 평일 운행의 역간 소요시간을 붙인다. 중간 역 TAGO 시각과 ±60초 안에서 맞는지 검증(열차 단위 확인 대신)
- GTX-A 는 평일·휴일 정거 수가 같다 → 시각까지 같으면 대상에서 뺀다(바꿀 것 없음)
- 인천2 는 인천교통공사 파일(열차 순번별 전 역 시각)을 받을 수 있으면 KRIC 방식으로 간다(활용신청 필요 여부 확인)
- PR-A/B 뒤에 계획 보강(방식이 다르다)

## 검증 (로컬 OTP)
- PR-A: 대상 노선 한 역의 휴일(일요일) 출발 목록이 KRIC 휴일과 같고 평일은 옛 그래프와 같다. 토요일 별도 노선(대구·부산·광주)은 토요일이 KRIC 토요일과 같다. 12-25 = 일요일과 같다
- PR-B: 교체 노선 평일 출발 목록이 KRIC 평일과 같다. 코퍼스 전후 비교에서 바뀐 경로는 **전 또는 후 중 하나가 교체 노선을 타는** 경로뿐이다(교체 노선은 주말도 바뀜)
- 공통: 평일 패턴 코드 목록(교체 안 한 노선)이 옛 그래프와 같다, OTP 힙이 옛 그래프 + 300 MB 안

## 리스크
- KRIC 기준일자가 노선마다 다르고 오래된 곳이 있다(부산 2022) → 관문이 KTDB 와의 차이를 보여주지만, 둘 다 낡았으면 못 잡는다

- 부산4 공휴일 = 일요일표, 광주 명절표 무시 — 근사
- KRIC 파일 형식이 노선마다 달라 파서 분기가 많다 → 노선별 시험 표본
- 채운 시각(부산·의정부 종착, 오타 역)은 KTDB 구간시간 근사 — 표시하고 리포트
