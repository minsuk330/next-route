# 지하철 요일별 시간표 (#557)

## 뭘 하나
PR-0: 시간표는 그대로 두고 운행 기간만 늘린 그래프를 12-22 전에 배포한다. PR-1: 3·7·8·9호선을 평일, 토요일, 휴일(일요일·공휴일)
시간표로 나눈다. 평일은 KTDB 그대로, 토·휴일은 서울 시간표 API 로 만든다. 4·5호선 → 1호선 → 2·6호선은 다음 단계.

## 왜
KTDB GTFS 는 2025년 3월 평일 하루를 매일 운행으로 배포해 11-08(일) 심야에 왕십리행 막차를 천호행으로 안내했다.
지금 그래프는 12-22 까지만 대중교통이 있다.

## 핵심 결정
- 운행 기간은 OTP 설정상 빌드일 + 2개월까지만 — 날짜 고정은 힙 +270 MB 라 기각, 약 6주마다 다시 빌드
- 대상 노선은 명시 목록 + 관문(평일 일치 ≥95%, 주말 unmatched ≤5%). 못 넘으면 지금 그대로 — 주말 운행 0 방지
- 토·휴일 운행은 같은 노선 평일 운행을 틀로 복사. 틀 없는 정차 패턴은 지어내지 않고 리포트
- 토·휴일 같은 열차는 열차 단위로 묶음(`M_SH`), 공휴일은 `calendar_dates.txt`(목록에 적용 범위 가드)
- 1·2·4·5·6호선은 갈래·순환·코레일 구간 때문에 지금 도구로 안 됨(실측) — 단계 분리
